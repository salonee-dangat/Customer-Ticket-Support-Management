# customer-ticket-support-management

This project is a Customer Support Ticket System designed to help businesses manage customer queries efficiently.

Features

- User authentication
- Create, update, and track support tickets
- Ticket status management (Open, In Progress, Resolved)
- Admin dashboard for managing tickets
- Responsive UI
- Tech Stack

Frontend: React
Backend: Node.js, Express
Database: MongoDB
Purpose This project is being developed as part of my internship to understand real-world application development and workflow using Git and Github.
